## Assessment

Choose one of two coding projects: a moving contact line or van der Waals film rupture. The code submission contributes 40% and the final presentation and defence contribute 60%. AI use is encouraged and must be documented in an AI log.

The [2026 course repository](https://github.com/comphy-lab/Intro-Soft-Matter-2026) contains the full brief, submission dates and pull-request instructions. It replaces the paper-led presentations used in 2025.
